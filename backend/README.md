# Backend

NestJS API — see the root [`README.md`](../README.md) for quick-start instructions and [`claude/backend.md`](../claude/backend.md) for architecture and conventions.

## Scripts

- `npm run start:dev` — local dev server with watch mode.
- `npm run prisma:migrate` — create/apply a migration locally.
- `npm run prisma:seed` — seed placeholder projects.
- `npm run prisma:studio` — browse the database.
- `npm run build` / `npm run start:prod` — production build and run.
- `npm run lint` / `npm run test` — lint and unit tests.
