# claude/ — Project Reference Index

The root [`CLAUDE.md`](../CLAUDE.md) holds durable, timeless engineering principles — it's auto-loaded every session and rarely changes. This folder holds the opposite: living, project-specific reference material that documents *this* portfolio's actual architecture, schema, design language, and plan. Read the relevant doc on demand before working in that area, and update it when the project's reality changes.

- [`architecture.md`](architecture.md) — monorepo layout, request flow, Docker Compose topology, env-var flow, dependency direction.
- [`backend.md`](backend.md) — NestJS module map, Controller → Service → Repository convention, DTO/validation approach, Swagger and error-handling conventions.
- [`frontend.md`](frontend.md) — feature-folder convention, routing map, data-fetching conventions, styling/animation rules, the CSR/SEO trade-off.
- [`design-system.md`](design-system.md) — color tokens, type scale, spacing, motion timing, explicit anti-patterns.
- [`database-schema.md`](database-schema.md) — Prisma models, field rationale, migration policy, seed data.
- [`roadmap.md`](roadmap.md) — phased plan: what's built, what's deferred, what's next.
