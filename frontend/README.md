# Frontend

React + Vite SPA — see the root [`README.md`](../README.md) for quick-start instructions and [`claude/frontend.md`](../claude/frontend.md) for architecture and conventions.

## Scripts

- `npm run dev` — local dev server.
- `npm run build` — typecheck and production build.
- `npm run lint` — oxlint.
- `npm run preview` — preview the production build locally.
